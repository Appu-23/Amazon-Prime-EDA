# 📺 Amazon Prime TV Shows and Movies Analysis

## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the Amazon Prime TV Shows and Movies dataset.

The objective is to analyze the content library, identify trends in:

- Genres
- Ratings
- Production countries
- Runtime
- Popularity
- Content growth patterns

The analysis generates actionable business insights that can support content acquisition and strategic decision-making.

---

## 🎯 Project Type

**Exploratory Data Analysis (EDA)**

---

# 📂 Dataset

The project uses two datasets:

### 1. titles.csv

Contains information about Amazon Prime movies and TV shows.

### Features:

- Title
- Content Type
- Release Year
- Runtime
- Genres
- Production Countries
- IMDb Score
- IMDb Votes
- TMDB Score
- TMDB Popularity
- Number of Seasons


### 2. credits.csv

Contains information about actors and directors.

### Features:

- Person ID
- Title ID
- Actor/Director Name
- Character Name
- Role

# 📈 Key Insights

✔ Movies dominate Amazon Prime's content library.

✔ The United States contributes the highest number of titles.

✔ Content production has increased significantly in recent decades.

✔ IMDb ratings and TMDB scores show a positive relationship.

✔ Popular genres receive higher audience engagement.

---

# 💼 Business Recommendations

Based on the analysis:

- Invest more in high-performing genres.
- Expand high-quality TV Show production.
- Increase partnerships with countries producing highly rated content.
- Prioritize content quality using audience ratings and popularity metrics.
- Continuously monitor content performance using data analytics.
